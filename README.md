# HSK Writing 写字

Listen to a Chinese word and write the character — HSK exam style, with spaced repetition like Anki.

## Features

- 🔊 **Listen-and-write practice** — hear each word, then type the pinyin and pick the character
- ⌨️ **HSK exam-style pinyin IME** — type pinyin (no tones), candidates appear, select the character
- 🧠 **Spaced repetition** — words you get right come back later (1 → 2 → 4 → 7 → 14 → 30 → 90 days); wrong answers reset
- 📊 **Progress tracking** — studied / mastered / accuracy stats, per-card history
- 💾 **Saves automatically** in your browser (localStorage)
- 📱 **Works on mobile** — responsive layout
- 🔉 **Native audio** — uses the original recordings from the HSK 3 Anki deck
